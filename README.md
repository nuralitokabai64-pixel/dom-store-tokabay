## Как открыть

Можно нажать на ссылку и открыть `index.html` в браузере. Проект не использует ES-модули, поэтому локальный сервер не обязателен — страница корректно работает через протокол `file://`.

---

## Возможности проекта

* **Динамический рендеринг:** Список товаров (мебель, материалы, фурнитура) отрисовывается в таблицу с расчетом промежуточных сумм.
* **Строгая валидация:** Форма добавления проверяет поля на лету без использования `alert`. Ошибки выводятся текстом под каждым полем ввода и исчезают при начале редактирования.
* **Интерактивность:** Кнопки «−» и «+» изменяют количество товара (с ограничением до 9999), кнопка «Удалить» полностью убирает позицию со склада.
* **Live Total:** Общая стоимость склада, количество уникальных позиций и общее число единиц пересчитываются мгновенно при любом изменении.
* **Обновление позиций:** Если добавить материал с существующим именем, скрипт обновит его количество и актуализирует цену, не создавая дубликатов.

## Архитектура и события

* **Единый источник истины:** Все данные хранятся в экземпляре класса `Store`. Любое действие пользователя сначала обновляет данные в объекте, а затем вызывает функцию `render()`, которая перестраивает интерфейс.
* **`<template>` и `textContent`:** Строки таблицы генерируются через HTML-тег `<template>`. Вставка данных происходит через `textContent` для защиты от XSS-атак.
* **Делегирование событий (`click`):** На контейнер списка навешен один слушатель событий. Через `e.target` и `data-атрибуты` скрипт определяет, какая кнопка была нажата. Это экономит память и позволяет кнопкам работать даже после перерисовки таблицы.
* Слушатели `submit` и `input` на форме предотвращают перезагрузку страницы и управляют показом ошибок.
